SER Stack (Quick Reference)
1. Data Engineering

Librosa: Core library for extracting MFCCs, Mel Spectrograms, and chroma features.

SoundFile / PyAudio: Standard I/O for reading/writing .wav and .flac.

Parselmouth: Pythonic Praat interface for pitch, intensity, and duration analysis.

OpenSMILE: Large-scale, standardized emotional feature set extraction.

-- Subject to Evaluation
2. Modeling & Inference

Traditional (Scikit-learn): Quick implementation of SVM, MLP, and Random Forest classifiers.

Deep Learning (PyTorch / TensorFlow): Preferred for CNNs (spectrogram analysis) and LSTMs (temporal patterns).

SpeechBrain: PyTorch-based framework with ready-to-use SER recipes.

3. SOTA / Pre-trained

Hugging Face Transformers: Access to Wav2Vec2.0 and HuBERT for transfer learning and high-accuracy inference.
